## 1. Purpose

WebCron은 웹 화면으로 크론 작업을 관리하는 상시 구동 서버이다. CLI 명령과 HTTP 웹훅(GET/POST)을 일정에 따라 실행하고, 실행 결과와 감사 로그를 웹에서 확인할 수 있게 한다. 이 SRS는 IEEE 29148 구조를 따르는 SRS-MD 규칙으로 작성한다.
